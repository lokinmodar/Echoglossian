# Task 4a Report: Source-Scoped Canonical Caches

## Status

Implemented and validated the cache-only Task 4a slice for action tooltips,
item tooltips, traits, reference text, and structured StringArrayData. This
commit does not complete the original Task 4 persistence, GameWindow,
registry, or caller-migration scope.

Commit: `#139 Scope canonical tooltip and StringArrayData caches` (this commit).

## Root Cause

The five cache implementations selected reusable rows by target language,
translation engine, game version, and source hash or stable identity, but did
not include persisted source language in their reusable lookup predicates or
text-map keys. Cache replacement predicates also omitted source language, so
otherwise identical English and Japanese rows could replace each other.

## Behavior

- Canonical, historical, identity, forward-text, and reverse-text reuse now
  evaluates `TranslationReuseScope.Matches(...)` where the cache supports that
  lookup shape.
- Text-map keys include normalized source, target, engine requirement, and
  game version.
- Cache replacement predicates include normalized stored source language while
  preserving target, engine, version, source-hash, and identity behavior.
- Legacy target/engine overloads remain temporarily so excluded callers compile.
  They resolve `SourceClientLanguage.PersistenceCode` and fail closed when the
  current source language cannot be resolved. Source-explicit reference-text
  adapters construct the same shared scope directly.
