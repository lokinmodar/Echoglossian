Echoglossian — это плагин Dalamud, который в реальном времени переводит поддерживаемые текстовые поверхности Final Fantasy XIV.

Эта публичная документация разделена для двух аудиторий:

- пользователей плагина, которым нужна помощь по установке, настройке, выбору режима и устранению проблем;
- участников, которым нужна справка по архитектуре, runtime и разработке.

## Что покрывает этот сайт

- Установку плагина из той launcher-экосистемы, которой вы уже пользуетесь.
- Настройку исходного и целевого языков.
- Выбор provider перевода и ввод собственных учётных данных в UI плагина.
- Понимание того, когда подходят режимы overlay, native и swap.
- Проверку того, какие поверхности сейчас документированы как поддерживаемые.

## Что этот сайт не публикует

- Секреты репозитория или действующие учётные данные.
- Внутренние handoff-заметки, backlog-и или приватные рабочие документы.
- Инструкции для release maintainer по внешним manifest.
