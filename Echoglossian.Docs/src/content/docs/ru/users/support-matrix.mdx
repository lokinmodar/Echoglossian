Эта страница — публичная версия текущего перечня поверхностей перевода. Здесь документируется только реальное поведение runtime.

## Семейства режимов

| Семейство режимов | Режимы | Используется в |
| --- | --- | --- |
| Семейство quest / native-window | `Native UI Translation`, `Tooltip Translation Only`, `Native UI Translation With Original Tooltips` | Поверхности семейства Journal и game windows DB-first |
| Семейство overlay | `Native UI Translation`, `Overlay Translation Only`, `Native UI Translation With Original Overlay` | Talk, BattleTalk, subtitles, MiniTalk, CutSceneSelectString и поверхности семейства toast |

## Операционные заметки

- Для некоторых языков нужны загруженные font assets, прежде чем перевод можно будет безопасно активировать.
- Языки overlay-only выводятся из native replacement modes, когда native-отображение было бы небезопасным.
- Поверхность может существовать в конфигурации или коде, но при этом быть намеренно скрытой или отключённой в release.
