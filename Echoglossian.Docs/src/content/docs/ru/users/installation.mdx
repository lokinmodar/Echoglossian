## Установите плагин

Установите Echoglossian через ту launcher-экосистему FFXIV и тот источник плагинов, который вы уже используете для плагинов Dalamud.

## Чеклист первого запуска

1. Откройте окно настройки Echoglossian командой `/eglo`.
2. Выберите исходный и целевой языки, с которыми хотите работать.
3. Выберите движок перевода, который поддерживает ваш целевой язык.
4. Введите собственные учётные данные provider в UI плагина, если движок этого требует.
5. Включите поверхности, которые хотите переводить.

## Правила активации

Глобальный перевод не остаётся включённым, пока не выполнены все следующие условия:

- Выбранный движок подходит для выбранного целевого языка.
- Конфигурация provider заполнена полностью.
- Присутствуют все необходимые загруженные font assets для целевого языка.

## Учётные данные и ключи

Учётные данные provider вводятся игроком в UI настройки плагина. Этот сайт документации не публикует и не требует секреты репозитория.

Используйте placeholders вроде `sk-example` только в примерах. Никогда не копируйте настоящий API key в скриншоты или общие логи.
