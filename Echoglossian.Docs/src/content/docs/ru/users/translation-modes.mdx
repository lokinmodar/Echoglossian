---
title: Режимы перевода
description: Разберитесь в представлениях overlay, native и swap перед включением поверхностей.
---

Echoglossian рассматривает захват, перевод, рендеринг overlay и native-модификацию как отдельные стадии. Режим представления решает, какие стадии могут касаться live UI игры.

## Overlay Translation Only

Используйте режим overlay, если хотите видеть перевод без мутации native addon.

- Исходный текст захватывается.
- Перевод выполняется как обычно.
- Переведённый результат рендерится только в overlay.
- Native addon остаётся только для чтения.

Это самый безопасный режим для плотных или нестабильных поверхностей.

## Native UI Translation

Используйте режим native, если хотите, чтобы переведённый текст записывался в поддерживаемые native-поверхности.

- Сначала всё равно происходят захват и перевод.
- Переведённый результат может быть записан в live addon.
- Качество раскладки зависит от того, насколько хорошо конкретная поверхность поддерживает native replacement.

## Native UI Translation With Original Overlay

Режим swap оставляет переведённый текст в native UI и использует overlay для показа исходного текста.

Это полезно, когда вам нужен переведённый UI, но рядом всё ещё нужно видеть оригинальную формулировку для справки.

## Как выбрать

Начинайте с режима overlay, если:

- вы тестируете новый движок;
- вы тестируете новый язык;
- вы работаете с плотной поверхностью, например journal или длинными диалогами.

Переходите к режиму native или swap только после того, как целевая поверхность ведёт себя достаточно хорошо в вашей конфигурации.
