## Базовые параметры

Минимально полезная конфигурация включает:

- исходный язык;
- целевой язык;
- движок перевода, который поддерживает эту пару;
- корректную конфигурацию provider, если движок требует учётные данные или endpoint.

## Конфигурация движка

Разные движки показывают разные поля, но публичные категории остаются стабильными:

- поля учётных данных vendor, например API key;
- выбор модели для движков на базе LLM;
- необязательный кастомный endpoint или URL локального runtime;
- параметры, связанные с prompt, для prompt-aware движков.

Если движок недоступен для выбранного целевого языка, смените либо движок, либо целевой язык, прежде чем пытаться глобально активировать перевод.

## Toggle для поверхностей

После того как глобальный переводчик работает штатно, включайте только нужные поверхности:

- поверхности диалогов и overlay;
- поверхности quest и journal;
- поверхности toast;
- поверхности game window.

У каждого семейства сохраняются собственные toggle для конкретных поверхностей даже после включения глобального перевода.

## Безопасные привычки настройки

- Меняйте по одной группе настроек за раз.
- Проверяйте связность provider перед включением большого числа поверхностей.
- Сначала предпочитайте presentation overlay при проверке нового языка или нового provider.
- Следите, чтобы в скриншотах и экспортированных настройках не было настоящих секретов provider.
