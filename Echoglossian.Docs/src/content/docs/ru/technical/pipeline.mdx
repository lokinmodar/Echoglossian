## Границы стадий

### Capture

Source text может приходить из:

- payload `AtkValue` до refresh
- видимых text node addon
- callback payload, таких как quest toast `SeString`

### Перевод

`TranslationService` координирует общий поток перевода. Конкретные translators остаются engine-specific и должны владеть только provider-specific request и response handling.

### Представление

- Режим overlay рендерит переведённый текст вне native UI.
- Режим native может записывать переведённый текст в поддерживаемые nodes или payloads.
- Режим swap сохраняет переведённый native text и использует overlay для original text.

### Persistence и reuse

Сущности диалога и toast используют persisted history плюс in-memory suppression, чтобы избегать повторной работы. Поздняя completion не должна перезаписывать более новый visible state, если её scope capture уже устарел.
