## Исследование addon

Используйте предпочтительную команду addon probe из репозитория, когда исследуете поведение native UI:

```text
/egloaddonprobe <addon>
```

Это первый инструмент, к которому стоит тянуться, когда конкретное семейство addon ведёт себя не так, как ожидается.

## Валидация build и test

Стандартная валидация plugin:

```powershell
dotnet build .\Echoglossian.sln -c Debug --no-restore
dotnet test .\Echoglossian.Tests\Echoglossian.Tests.csproj -c Debug --no-build
```

Валидация docs site:

```powershell
Set-Location .\Echoglossian.Docs
npm.cmd run test:locales
npm.cmd run check:locales
npm.cmd run check
npm.cmd run build
```

## Принципы диагностики

- предпочитайте lifecycle helper-ы и точечные probes вместо hot-path debug spam
- убирайте временный investigation logging, как только проблема понятна
- классифицируйте runtime issues по стадиям, прежде чем менять код
