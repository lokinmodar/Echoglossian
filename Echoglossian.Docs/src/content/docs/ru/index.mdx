## Публичная область

Этот сайт публикует только курируемую документацию.

- Здесь публикуются материалы по использованию, настройке и устранению проблем плагина.
- Здесь публикуются текущая архитектура, поток runtime и руководство для участников.
- Внутренние handoff-заметки, release-заметки, планы и backlog-материалы остаются в дереве `docs/` репозитория и не публикуются на этом сайте.

## Модель локализации

Сайт публикует тот же список locale, что и файлы ресурсов плагина. English — нейтральная исходная locale. Если локализованная страница ещё не существует, Starlight показывает английскую страницу со своим встроенным уведомлением о непереведённом содержимом вместо того, чтобы создавать сломанный route.
