## Âmbito público

Este site publica apenas documentação curada.

- A utilização, a configuração e a resolução de problemas do plugin são publicadas aqui.
- A arquitetura atual, o fluxo de runtime e a orientação para contribuidores são publicados aqui.
- Handoffs internos, notas de release, planos e material de backlog permanecem na árvore `docs/` do repositório e não são publicados por este site.

## Modelo de localização

O site expõe a mesma lista de locales que os ficheiros de recursos do plugin. O inglês é a locale de origem neutra. Se uma página localizada ainda não existir, o Starlight apresenta a página em inglês com o seu aviso integrado de conteúdo não traduzido em vez de produzir uma route quebrada.
