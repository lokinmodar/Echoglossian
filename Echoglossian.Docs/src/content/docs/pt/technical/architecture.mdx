## Áreas principais do runtime

- `NativeUI/AddonHandlers/...` para comportamento de captura e apresentação específico por addon
- `NativeUI/Handlers/...` para helpers native partilhados e coordenação de runtime
- `UIOverlays/TranslationOverlay/...` para estado e rendering do overlay
- `Translators/TranslationService` para o fluxo de tradução partilhado
- `LanguagesHandling/...` para metadados de idioma e disponibilidade de engine
- `DBHelpers/...` e entidades de mensagens suportadas por EF para histórico persistido de tradução

## Regras de arquitetura

- O trabalho novo deve reutilizar o pipeline de tradução partilhado em vez de criar uma fila paralela.
- O modo overlay-only tem de manter a native game UI em modo só de leitura.
- Os modos native e swap só podem mutar a native UI em surfaces que o suportem explicitamente.
- A base de dados continua a ser a fonte de verdade. Os caches em memória servem para suprimir trabalho repetido, não para redefinir a semântica de persistência.

## Limite da documentação

Este site público descreve a arquitetura ao nível de contribuidores. Não publica handoffs internos nem notas de scratch específicas de issues da árvore `docs/` do repositório.
