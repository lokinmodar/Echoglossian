## Regras do repositório para este site

- `Echoglossian.Docs/` não faz intencionalmente parte de `Echoglossian.sln`.
- O projeto raiz do plugin exclui explicitamente a árvore docs de `Compile`, `EmbeddedResource` e `None`.
- O fluxo de deploy das docs é separado do fluxo de release do plugin e do D17.

## Validação local

Validação do plugin:

```powershell
dotnet build .\Echoglossian.sln -c Debug --no-restore
dotnet test .\Echoglossian.Tests\Echoglossian.Tests.csproj -c Debug --no-build
```

Validação do site docs:

```powershell
Set-Location .\Echoglossian.Docs
npm.cmd ci
npm.cmd run test:locales
npm.cmd run check:locales
npm.cmd run check
npm.cmd run build
```

## Expectativas de contribuição

- mantenha as alterações estreitas
- preserve o comportamento atual, a menos que a alteração vise explicitamente o comportamento
- reutilize a arquitetura partilhada do plugin em vez de introduzir caminhos paralelos
- mantenha as docs públicas curadas e específicas para a audiência em vez de publicar notas internas tal como estão

## Limite de release

Este site público de documentação não descreve intencionalmente o fluxo privado do release maintainer para submissão de manifests externos. Esse workflow permanece na documentação interna do repositório.
