Esta página é a versão pública do inventário atual de superfícies de tradução. Documenta apenas comportamento real de runtime.

## Famílias de modos

| Família de modos | Modos | Utilizada por |
| --- | --- | --- |
| Família quest / native-window | `Native UI Translation`, `Tooltip Translation Only`, `Native UI Translation With Original Tooltips` | Superfícies da família Journal e game windows DB-first |
| Família overlay | `Native UI Translation`, `Overlay Translation Only`, `Native UI Translation With Original Overlay` | Talk, BattleTalk, subtitles, MiniTalk, CutSceneSelectString e superfícies da família toast |

## Notas operacionais

- Alguns idiomas exigem assets de fontes descarregados antes de a tradução poder ser ativada em segurança.
- Idiomas overlay-only são normalizados para fora dos modos de substituição native quando a apresentação native seria insegura.
- Uma superfície pode existir na configuração ou no código e ainda assim estar intencionalmente oculta ou desativada numa release.
