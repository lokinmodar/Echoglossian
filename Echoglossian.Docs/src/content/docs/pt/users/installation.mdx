## Instalar o plugin

Instale o Echoglossian através do ecossistema de launcher FFXIV e da origem de plugins que já utiliza para plugins Dalamud.

## Checklist da primeira execução

1. Abra a janela de configuração do Echoglossian com `/eglo`.
2. Escolha os idiomas de origem e de destino com que quer trabalhar.
3. Selecione um motor de tradução que suporte o seu idioma de destino.
4. Introduza a sua própria credencial do provider na UI do plugin se o motor a exigir.
5. Ative as superfícies que quer traduzir.

## Regras de ativação

A tradução global não permanece ativada a menos que todas as condições seguintes sejam verdadeiras:

- O motor selecionado é válido para o idioma de destino selecionado.
- A configuração do provider está completa.
- Quaisquer assets de fontes descarregados necessários para o idioma de destino estão presentes.

## Credenciais e chaves
