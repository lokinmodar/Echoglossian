O Echoglossian é um plugin Dalamud que traduz em tempo real superfícies de texto suportadas do Final Fantasy XIV.

Esta documentação pública está dividida em dois públicos:

- usuários do plugin que precisam de orientação sobre instalação, configuração, escolha de modo e solução de problemas;
- contribuidores que precisam de referência sobre arquitetura, runtime e desenvolvimento.

## O que este site cobre

- Instalar o plugin a partir do ecossistema de launcher que você já usa.
- Configurar os idiomas de origem e de destino.
- Selecionar um provider de tradução e inserir suas próprias credenciais na UI do plugin.
- Entender quando as apresentações overlay, native e swap são apropriadas.
- Verificar quais superfícies estão atualmente documentadas como suportadas.

## O que este site não publica

- Segredos do repositório ou credenciais ativas.
- Notas internas de handoff, backlogs ou documentos privados de workflow.
- Instruções de release maintainer para manifests externos.
