## Instale o plugin

Instale o Echoglossian por meio do ecossistema de launcher FFXIV e da fonte de plugins que você já usa para plugins Dalamud.

## Checklist da primeira execução

1. Abra a janela de configuração do Echoglossian com `/eglo`.
2. Escolha os idiomas de origem e de destino com os quais você quer trabalhar.
3. Selecione um motor de tradução que suporte seu idioma de destino.
4. Insira sua própria credencial do provider na UI do plugin se o motor exigir isso.
5. Ative as superfícies que você quer traduzir.

## Regras de ativação

A tradução global não permanece ativada a menos que todas as condições abaixo sejam verdadeiras:

- O motor selecionado é válido para o idioma de destino selecionado.
- A configuração do provider está completa.
- Quaisquer assets de fonte baixados exigidos para o idioma de destino estão presentes.
