## Escopo público

Este site publica apenas documentação curada.

- O uso, a configuração e a solução de problemas do plugin são publicados aqui.
- A arquitetura atual, o fluxo de runtime e o guia para contribuidores são publicados aqui.
- Handoffs internos, notas de release, planos e material de backlog permanecem na árvore `docs/` do repositório e não são publicados por este site.

## Modelo de localização

O site expõe a mesma lista de locales dos arquivos de recursos do plugin. O inglês é a locale de origem neutra. Se uma página localizada ainda não existir, o Starlight renderiza a página em inglês com seu aviso interno de conteúdo não traduzido em vez de produzir uma rota quebrada.
