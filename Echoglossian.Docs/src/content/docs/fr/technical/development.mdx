## Règles du dépôt pour ce site

- `Echoglossian.Docs/` ne fait volontairement pas partie de `Echoglossian.sln`.
- Le projet racine du plugin exclut explicitement l’arbre docs de `Compile`, `EmbeddedResource` et `None`.
- Le flux de déploiement des docs est séparé du flux de release du plugin et de D17.

## Validation locale

Validation du plugin :

```powershell
dotnet build .\Echoglossian.sln -c Debug --no-restore
dotnet test .\Echoglossian.Tests\Echoglossian.Tests.csproj -c Debug --no-build
```

Validation du site de docs :

```powershell
Set-Location .\Echoglossian.Docs
npm.cmd ci
npm.cmd run test:locales
npm.cmd run check:locales
npm.cmd run check
npm.cmd run build
```

## Attentes de contribution

- garder les changements étroits
- préserver le comportement actuel sauf si le changement vise explicitement le comportement
- réutiliser l’architecture partagée du plugin au lieu d’introduire des chemins parallèles
- garder les docs publiques curatées et spécifiques à leur audience au lieu de publier telles quelles des notes internes

## Limite de release

Ce site public de documentation ne décrit volontairement pas le flux privé du release maintainer pour la soumission de manifests externes. Ce workflow reste dans la documentation interne du dépôt.
