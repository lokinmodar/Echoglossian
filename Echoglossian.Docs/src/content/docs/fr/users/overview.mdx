Echoglossian est un plugin Dalamud qui traduit en temps réel les surfaces de texte prises en charge dans Final Fantasy XIV.

Cette documentation publique s’adresse à deux publics :

- les utilisateurs du plugin qui ont besoin d’aide pour l’installation, la configuration, le choix du mode et le dépannage ;
- les contributeurs qui ont besoin d’une référence sur l’architecture, l’exécution et le développement.

## Ce que ce site couvre

- Installer le plugin depuis l’écosystème de launcher que vous utilisez déjà.
- Configurer les langues source et cible.
- Sélectionner un provider de traduction et saisir vos propres identifiants dans l’UI du plugin.
- Comprendre quand les présentations overlay, native et swap sont appropriées.
- Vérifier quelles surfaces sont actuellement documentées comme prises en charge.

## Ce que ce site ne publie pas

- Les secrets du dépôt ou des identifiants actifs.
- Les notes de handoff internes, les backlogs ou les notes de travail privées.
- Les instructions de release maintainer pour les manifests externes.
