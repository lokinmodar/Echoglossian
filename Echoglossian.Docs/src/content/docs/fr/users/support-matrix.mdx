Cette page est la version publique de l’inventaire actuel des surfaces de traduction. Elle documente uniquement le comportement réel à l’exécution.

## Familles de modes

| Famille de modes | Modes | Utilisé par |
| --- | --- | --- |
| Famille quêtes / fenêtres natives | `Native UI Translation`, `Tooltip Translation Only`, `Native UI Translation With Original Tooltips` | Surfaces de la famille Journal et game windows DB-first |
| Famille overlay | `Native UI Translation`, `Overlay Translation Only`, `Native UI Translation With Original Overlay` | Talk, BattleTalk, subtitles, MiniTalk, CutSceneSelectString et surfaces de la famille toast |

## Notes d’exploitation

- Certaines langues exigent des ressources de police téléchargées avant que la traduction puisse s’activer en toute sécurité.
- Les langues overlay-only sont normalisées en dehors des modes de remplacement natif lorsque l’affichage natif serait dangereux.
- Une surface peut exister dans la configuration ou le code tout en restant intentionnellement masquée ou désactivée dans une release.
