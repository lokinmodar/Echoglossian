## Installer le plugin

Installez Echoglossian via l’écosystème de launcher FFXIV et la source de plugins que vous utilisez déjà pour les plugins Dalamud.

## Checklist du premier lancement

1. Ouvrez la fenêtre de configuration d’Echoglossian avec `/eglo`.
2. Choisissez les langues source et cible avec lesquelles vous voulez travailler.
3. Sélectionnez un moteur de traduction qui prend en charge votre langue cible.
4. Saisissez votre propre identifiant de provider dans l’UI du plugin si le moteur l’exige.
5. Activez les surfaces que vous souhaitez traduire.

## Règles d’activation

La traduction globale ne reste pas activée tant que toutes les conditions suivantes ne sont pas vraies :

- Le moteur sélectionné est valide pour la langue cible sélectionnée.
- La configuration du provider est complète.
- Les éventuelles ressources de police téléchargées requises pour la langue cible sont présentes.

## Identifiants et clés

Les identifiants de provider sont saisis par le joueur dans l’UI de configuration du plugin. Ce site de documentation ne publie pas et n’exige pas de secrets du dépôt.

Utilisez uniquement des placeholders comme `sk-example` dans les exemples. Ne copiez jamais une vraie clé API dans des captures d’écran ou des logs partagés.
