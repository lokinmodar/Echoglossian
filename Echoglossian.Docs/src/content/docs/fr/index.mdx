## Portée publique

Ce site publie uniquement de la documentation curatée.

- L’usage, la configuration et le dépannage du plugin sont publiés ici.
- L’architecture actuelle, le flux d’exécution et la documentation pour les contributeurs sont publiés ici.
- Les notes de handoff internes, les notes de release, les plans et le matériel de backlog restent dans l’arborescence `docs/` du dépôt et ne sont pas publiés par ce site.

## Modèle de localisation

Le site expose la même liste de locales que les fichiers de ressources du plugin. L’anglais est la locale source neutre. Si une page localisée n’existe pas encore, Starlight affiche la page anglaise avec son avis intégré de contenu non traduit au lieu de produire une route cassée.
