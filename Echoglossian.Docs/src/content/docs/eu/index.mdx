## Esparru publikoa

Gune honek dokumentazio landua baino ez du argitaratzen.

- Pluginaren erabilera, konfigurazioa eta arazoen konponketa hemen argitaratzen dira.
- Uneko arkitektura, runtime fluxua eta laguntzaileentzako gidak hemen argitaratzen dira.
- Barne handoff-ak, release oharrak, planak eta backlog materiala repositoryko `docs/` zuhaitzean geratzen dira eta ez dira gune honetan argitaratzen.
