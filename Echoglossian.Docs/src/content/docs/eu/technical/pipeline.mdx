## Etapa mugak

### Capture

Source text honetatik etor daiteke:

- refresh aurreko `AtkValue` payloadetatik
- ikusgai dauden addon text node-etatik
- callback payloadetatik, adibidez quest toast `SeString`

### Itzulpena

`TranslationService`-k itzulpen-fluxu partekatua koordinatzen du. Translator konkretuek engine-specific izaten jarraitzen dute eta provider-specific request eta response handling bakarrik eduki behar dute.

### Aurkezpena

- Overlay moduak itzulitako testua native UI-tik kanpo renderizatzen du.
- Native moduak itzulitako testua onartutako node edo payloadetan idatz dezake.
- Swap moduak itzulitako native text mantentzen du eta overlaya erabiltzen du original text-erako.

### Persistence eta reuse

Dialogue eta toast entitateek persisted history gehi in-memory suppression erabiltzen dute errepikapenak saihesteko. Berandu bukatutako eskaera batek ez du visible state berriagoa ordezkatu behar bere capture scope-a zaharkituta geratu denean.
