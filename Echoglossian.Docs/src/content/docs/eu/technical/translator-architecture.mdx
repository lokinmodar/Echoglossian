## Ardura partekatuak

Runtime partekatuak honakoak kudeatzen ditu:

- itzultzaile-hautaketa
- request orkestrazioa
- cache reuse mugak
- persistence-ra ematea
- overlay eta native publication itzulpenaren ondoren

## Engine-specific ardurak

Engine adapter bakoitzak honako hauek bakarrik kudeatu behar ditu:

- provider client konfigurazioa
- request payload forma
- response analisia
- modelo katalogoaren jokabidea
- engine-specific configuration UI

## Egungo engine familiak

- vendor translation engineak, hala nola Google, DeepL, Microsoft, Amazon eta Yandex aldaerak
- OpenAI estiloko chat-completions engineak, hala nola OpenAI, OpenRouter, DeepSeek eta LM Studio
- Gemini `generateContent`
- Ollama local generation
- Claude Messages API

## Engine lanean aritzeko arau segurua

Engine bat gehitzean edo aldatzean:

1. berrerabili `TranslationService` eta `ITranslator`
2. eguneratu language support eta factory wiring aldaketa berean
3. mantendu provider-specific logika estua
4. balidatu build eta testak berehala engine mailako aldaketaren ondoren
