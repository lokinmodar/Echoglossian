## Runtime eremu nagusiak

- `NativeUI/AddonHandlers/...` addon bakoitzeko capture eta aurkezpen jokabiderako
- `NativeUI/Handlers/...` native laguntzaile partekatuetarako eta runtime koordinaziorako
- `UIOverlays/TranslationOverlay/...` overlay egoerarako eta rendering-erako
- `Translators/TranslationService` itzulpen-fluxu partekaturako
- `LanguagesHandling/...` hizkuntza metadata eta engine erabilgarritasunerako
- `DBHelpers/...` eta EF bidezko mezu-entitateak persisted itzulpen-historiarako

## Arkitektura arauak

- Lan berriak itzulpen pipeline partekatua berrerabili behar du, ez ilara paralelo bat sortu.
- Overlay-only moduak native game UI irakurtzeko soilik utzi behar du.
- Native eta swap moduek native UI bakarrik mutatu dezakete hori berariaz onartzen duten surfacesetan.
- Datu-basea egiaren iturria da. In-memory cacheak errepikatutako lana kentzeko dira, ez persistence semantics berridazteko.

Gune publiko honek arkitektura ekarpen-egileen mailan deskribatzen du. Ez ditu repositoryko `docs/` zuhaitzeko barne handoff-ak edo issueei lotutako scratch oharrak argitaratzen.
