Orrialde hau egungo itzulpen-azaleren inbentarioaren bertsio publikoa da. Runtime portaera erreala bakarrik dokumentatzen du.

## Modu-familiak

| Modu-familia | Moduak | Honek erabiltzen du |
| --- | --- | --- |
| Quest / native-window familia | `Native UI Translation`, `Tooltip Translation Only`, `Native UI Translation With Original Tooltips` | Journal familiako azalerak eta DB-first game windows |
| Overlay familia | `Native UI Translation`, `Overlay Translation Only`, `Native UI Translation With Original Overlay` | Talk, BattleTalk, azpitituluak, MiniTalk, CutSceneSelectString eta toast familiako azalerak |

## Eragiketa-oharrak

- Hizkuntza batzuek deskargatutako font assets behar dituzte itzulpena segurtasunez aktibatu aurretik.
- Overlay-only hizkuntzak native replacement moduetatik urruntzen dira native bistaratzea arriskutsua litzatekeenean.
- Azalera bat konfigurazioan edo kodean existi daiteke eta hala ere release batean nahita ezkutatuta edo desgaituta egon.
