Echoglossian Dalamud plugin bat da, Final Fantasy XIV-ko testu-azalera bateragarriak denbora errealean itzultzen dituena.

Dokumentazio publiko hau bi publikoentzako banatuta dago:

- Instalazio, konfigurazio, modu-hautaketa eta arazoen konponketa behar duten pluginaren erabiltzaileak.
- Arkitektura, runtime eta garapen erreferentzia behar duten laguntzaileak.

## Gune honek zer estaltzen duen

- Plugina jada erabiltzen duzun launcher ekosistematik instalatzea.
- Jatorrizko eta helburuko hizkuntzak konfiguratzea.
- Itzulpen-provider bat aukeratzea eta zure kredentzialak pluginaren UI-an sartzea.
- Overlay, native eta swap aurkezpena noiz diren egokiak ulertzea.
- Une honetan zein azalera dauden bateragarri gisa dokumentatuta egiaztatzea.

## Gune honek zer ez duen argitaratzen

- Repository secrets edo kredentzial aktiboak.
- Barne handoff oharrak, backlog-ak edo workflow pribatuen zirriborroak.
- Kanpoko manifestetarako release-maintainer argibideak.
