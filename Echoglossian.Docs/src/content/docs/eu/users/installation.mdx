## Instalatu plugina

Instalatu Echoglossian FFXIV launcher ekosistemaren eta jada erabiltzen duzun Dalamud plugin iturriaren bidez.

## Lehen exekuzioko egiaztapen-zerrenda

1. Ireki Echoglossian konfigurazio leihoa `/eglo` erabiliz.
2. Aukeratu erabili nahi dituzun jatorrizko eta helburuko hizkuntzak.
3. Aukeratu zure helburuko hizkuntza onartzen duen itzulpen-motorra.
4. Sartu provider-aren zure kredentzialak pluginaren UI-an, motorrak hala eskatzen badu.
5. Gaitu itzuli nahi dituzun azalerak.

## Aktibazio-arauak

Itzulpen globala ez da aktibo mantentzen, honako guztiak egia ez badira:

- Aukeratutako motorra balioduna da aukeratutako helburuko hizkuntzarako.
- Provider konfigurazioa osatuta dago.
- Helburuko hizkuntzarako beharrezko deskargatutako font assets-ak presente daude.

## Kredentzialak eta gakoak

Provider-aren kredentzialak jokalariak pluginaren konfigurazio UI-an sartzen ditu. Dokumentazio gune honek ez ditu repository secrets-ak argitaratzen eta ez ditu behar.

Erabili adibideetan `sk-example` bezalako placeholderrak bakarrik. Ez kopiatu inoiz benetako API key bat screenshot edo partekatutako log batean.
