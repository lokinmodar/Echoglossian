## Investigación de addons

Usa el comando de addon probe preferido del repo cuando investigues comportamiento de native UI:

```text
/egloaddonprobe <addon>
```

Es la primera herramienta a la que acudir cuando una familia específica de addons se comporta distinto de lo esperado.

## Validación de build y test

Validación estándar del plugin:

```powershell
dotnet build .\Echoglossian.sln -c Debug --no-restore
dotnet test .\Echoglossian.Tests\Echoglossian.Tests.csproj -c Debug --no-build
```

Validación del sitio de docs:

```powershell
Set-Location .\Echoglossian.Docs
npm.cmd run test:locales
npm.cmd run check:locales
npm.cmd run check
npm.cmd run build
```

## Principios de diagnóstico

- prefiere helpers de lifecycle y probes enfocados antes que debug spam en hot paths
- elimina el logging temporal de investigación una vez que entiendas el issue
- clasifica los problemas de runtime por etapa antes de cambiar código
