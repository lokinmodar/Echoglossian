## Alcance público

Este sitio publica solo documentación curada.

- El uso, la configuración y la resolución de problemas del plugin se publican aquí.
- La arquitectura actual, el flujo de runtime y la guía para contribuidores se publican aquí.
- Los handoffs internos, notas de release, planes y material de backlog permanecen en el árbol `docs/` del repositorio y no se publican en este sitio.
