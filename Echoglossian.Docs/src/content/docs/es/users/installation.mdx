## Instala el plugin

Instala Echoglossian mediante el ecosistema de launcher de FFXIV y la fuente de plugins que ya usas para plugins de Dalamud.

## Lista de verificación de la primera ejecución

1. Abre la ventana de configuración de Echoglossian con `/eglo`.
2. Elige el idioma de origen y el idioma de destino con los que quieres trabajar.
3. Selecciona un motor de traducción que admita tu idioma de destino.
4. Introduce tus propias credenciales del provider en la UI del plugin si el motor lo requiere.
5. Activa las superficies que quieras traducir.

## Reglas de activación

La traducción global no permanece activada a menos que se cumpla todo lo siguiente:

- El motor seleccionado es válido para el idioma de destino seleccionado.
- La configuración del provider está completa.
- Los font assets descargados requeridos para el idioma de destino están presentes.

## Credenciales y claves

Las credenciales del provider las introduce el jugador dentro de la UI de configuración del plugin. Este sitio de documentación no publica ni requiere secrets del repositorio.

Usa solo placeholders como `sk-example` en los ejemplos. Nunca copies una clave real de API en capturas o logs compartidos.
