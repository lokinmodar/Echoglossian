Echoglossian es un plugin de Dalamud que traduce en tiempo real superficies de texto compatibles de Final Fantasy XIV.

Esta documentación pública se divide en dos públicos:

- Usuarios del plugin que necesitan guía de instalación, configuración, elección de modo y resolución de problemas.
- Contribuidores que necesitan referencia de arquitectura, runtime y desarrollo.

## Qué cubre este sitio

- Instalar el plugin desde el ecosistema de launcher que ya utilizas.
- Configurar idioma de origen e idioma de destino.
- Elegir un provider de traducción e introducir tus propias credenciales en la UI del plugin.
- Entender cuándo es apropiada la presentación overlay, native y swap.
- Comprobar qué superficies están documentadas actualmente como compatibles.

## Qué no publica este sitio

- Secrets del repositorio ni credenciales activas.
- Notas internas de handoff, backlogs o borradores privados de workflow.
- Instrucciones de release-maintainer para manifests externos.
