Esta página es la versión pública del inventario actual de superficies de traducción. Documenta únicamente comportamiento real de runtime.

## Familias de modos

| Familia de modos | Modos | Utilizado por |
| --- | --- | --- |
| Familia quest / native-window | `Native UI Translation`, `Tooltip Translation Only`, `Native UI Translation With Original Tooltips` | Superficies de la familia Journal y DB-first game windows |
| Familia overlay | `Native UI Translation`, `Overlay Translation Only`, `Native UI Translation With Original Overlay` | Talk, BattleTalk, subtítulos, MiniTalk, CutSceneSelectString y superficies de la familia toast |

## Notas operativas

- Algunos idiomas requieren font assets descargados antes de que la traducción pueda activarse con seguridad.
- Los idiomas solo-overlay se normalizan para salir de los modos de native replacement cuando la visualización native sería insegura.
- Una superficie puede existir en la configuración o en el código y aun así estar oculta o desactivada intencionadamente en una release.
