## Primære runtime-områder

- `NativeUI/AddonHandlers/...` til addon-specifik capture- og præsentationsadfærd
- `NativeUI/Handlers/...` til delte native hjælpere og runtime-koordinering
- `UIOverlays/TranslationOverlay/...` til overlay-tilstand og rendering
- `Translators/TranslationService` til delt oversættelsesflow
- `LanguagesHandling/...` til sprogmetadata og engine-tilgængelighed
- `DBHelpers/...` og EF-baserede beskedentiteter til vedvarende oversættelseshistorik

## Arkitekturregler

- Nyt arbejde skal genbruge den delte oversættelsespipeline i stedet for at oprette en parallel kø.
- Overlay-only-tilstand skal holde den native game UI skrivebeskyttet.
- Native- og swap-tilstande må kun mutere native UI på overflader, der udtrykkeligt understøtter det.
- Databasen forbliver sandhedskilden. In-memory-caches er der for at undertrykke gentaget arbejde, ikke for at omdefinere persistenssemantik.

## Dokumentationsgrænse

Dette offentlige site beskriver arkitekturen på bidragsyderniveau. Det udgiver ikke interne handoffs eller issuespecifikke scratch-noter fra repositoryets `docs/`-træ.
