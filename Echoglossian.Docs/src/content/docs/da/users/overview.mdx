Echoglossian er et Dalamud-plugin, der oversætter understøttede tekstflader i Final Fantasy XIV i realtid.

Denne offentlige dokumentation er delt op efter to målgrupper:

- Plugin-brugere, der har brug for vejledning til installation, konfiguration, valg af tilstand og fejlfinding.
- Bidragydere, der har brug for reference til arkitektur, runtime og udvikling.

## Hvad dette site dækker

- Installation af plugin'et fra launcher-økosystemet, du allerede bruger.
- Konfiguration af kilde- og målsprog.
- Valg af oversættelsesprovider og indtastning af egne legitimationsoplysninger i plugin-UI'et.
- Forståelse af hvornår overlay-, native- og swap-visning er passende.
- Kontrol af hvilke flader der aktuelt er dokumenteret som understøttede.

## Hvad dette site ikke udgiver

- Repository-secrets eller aktive legitimationsoplysninger.
- Interne handoff-noter, backlogs eller private workflow-kladder.
- Release-maintainer-instruktioner til eksterne manifests.
