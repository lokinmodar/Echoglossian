Denne side er den offentlige version af den aktuelle oversigt over oversættelsesflader. Den dokumenterer kun reel runtime-adfærd.

## Tilstandsfamilier

| Tilstandsfamilie | Tilstande | Bruges af |
| --- | --- | --- |
| Quest-/native-window-familie | `Native UI Translation`, `Tooltip Translation Only`, `Native UI Translation With Original Tooltips` | Journal-familieflader og DB-first game windows |
| Overlay-familie | `Native UI Translation`, `Overlay Translation Only`, `Native UI Translation With Original Overlay` | Talk, BattleTalk, undertekster, MiniTalk, CutSceneSelectString og toast-familieflader |

## Driftsnoter

- Nogle sprog kræver downloadede font-assets, før oversættelse kan aktiveres sikkert.
- Overlay-only-sprog normaliseres væk fra native replacement-tilstande, når native visning ville være usikker.
- En flade kan eksistere i konfiguration eller kode, men stadig være bevidst skjult eller deaktiveret i en release.
