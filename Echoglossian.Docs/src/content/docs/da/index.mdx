## Offentligt omfang

Dette site udgiver kun kurateret dokumentation.

- Brug af plugin'et, opsætning, konfiguration og fejlfinding ligger her.
- Nuværende arkitektur, runtime-flow og vejledning til bidragydere ligger her.
- Interne handoffs, release-noter, planer og backlogmateriale bliver i repositoryets `docs/`-træ og udgives ikke på dette site.
