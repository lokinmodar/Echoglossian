## Public Scope

This site publishes curated documentation only.

- Plugin usage, setup, configuration, and troubleshooting live here.
- Current architecture, runtime flow, and contributor guidance live here.
- Internal handoffs, release-maintainer notes, plans, and backlog material stay in the repository `docs/` tree and are not published by this site.

## Localization Model

The site exposes the same locale list as the plugin resource files. English is the neutral source locale. If a localized page does not exist yet, Starlight renders the English page with its built-in untranslated-content notice instead of producing a broken route.
