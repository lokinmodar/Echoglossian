Echoglossian is a Dalamud plugin that translates supported Final Fantasy XIV text surfaces in real time.

This public documentation is split into two audiences:

- Plugin users who need installation, configuration, mode-selection, and troubleshooting guidance.
- Contributors who need architecture, runtime, and development reference.

## What This Site Covers

- Installing the plugin from the launcher ecosystem you already use.
- Configuring source and target languages.
- Selecting a translation provider and entering your own credentials in the plugin UI.
- Understanding when overlay, native, and swap presentation are appropriate.
- Checking which surfaces are currently documented as supported.

## What This Site Does Not Publish

- Repository secrets or live credentials.
- Internal handoff notes, backlogs, or private workflow scratch docs.
- Release-maintainer instructions for external manifests.
