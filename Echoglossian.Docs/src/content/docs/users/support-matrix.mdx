This page is the public version of the current translation-surface inventory. It documents real runtime behavior only.

## Mode Families

| Mode family | Modes | Used by |
| --- | --- | --- |
| Quest / native-window family | `Native UI Translation`, `Tooltip Translation Only`, `Native UI Translation With Original Tooltips` | Journal-family surfaces and DB-first game windows |
| Overlay family | `Native UI Translation`, `Overlay Translation Only`, `Native UI Translation With Original Overlay` | Talk, BattleTalk, subtitles, MiniTalk, CutSceneSelectString, and toast-family surfaces |
| Native / distance-aware hybrid family | `Native UI Translation`, `Tooltip Translation Only`, `Native UI Translation With Original Tooltips` | NamePlates use native presentation for standard languages and distance-aware overlay fallback for overlay-only languages |

## Operational Notes

- Some languages require downloaded font assets before translation can activate safely.
- Overlay-only languages are normalized away from native replacement modes when native display would be unsafe.
- NamePlates keep native presentation for standard languages, but switch to the distance-aware overlay backend when the current language is overlay-only.
- A surface may exist in config or code but still be intentionally hidden or disabled in a release.
