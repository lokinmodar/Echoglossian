## Install The Plugin

Install Echoglossian through the FFXIV launcher ecosystem and plugin source you already use for Dalamud plugins.

## First-Run Checklist

1. Open the Echoglossian configuration window with `/eglo`.
2. Choose the source and target languages you want to work with.
3. Select a translation engine that supports your target language.
4. Enter your own provider credential in the plugin UI if the engine requires one.
5. Enable the surfaces you want translated.

## Activation Rules

Global translation does not stay enabled unless all of the following are true:

- The selected engine is valid for the selected target language.
- The provider configuration is complete.
- Any required downloaded font assets for the target language are present.

## Credentials and Keys

Provider credentials are entered by the player inside the plugin configuration UI. This documentation site does not publish or require repository secrets.

Use placeholders such as `sk-example` in examples only. Never copy a real API key into screenshots or shared logs.
