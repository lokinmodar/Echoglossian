## Κύριες περιοχές runtime

- `NativeUI/AddonHandlers/...` για συμπεριφορά capture και παρουσίασης ανά addon
- `NativeUI/Handlers/...` για κοινά native βοηθήματα και συντονισμό runtime
- `UIOverlays/TranslationOverlay/...` για κατάσταση overlay και rendering
- `Translators/TranslationService` για την κοινή ροή μετάφρασης
- `LanguagesHandling/...` για metadata γλώσσας και διαθεσιμότητα engine
- `DBHelpers/...` και οντότητες μηνυμάτων με EF για persisted ιστορικό μετάφρασης

## Κανόνες αρχιτεκτονικής

- Η νέα δουλειά πρέπει να επαναχρησιμοποιεί το κοινό pipeline μετάφρασης αντί να δημιουργεί παράλληλη ουρά.
- Το overlay-only mode πρέπει να αφήνει το native game UI μόνο για ανάγνωση.
- Τα native και swap modes μπορούν να μεταβάλλουν native UI μόνο σε surfaces που το υποστηρίζουν ρητά.
- Η βάση δεδομένων παραμένει η πηγή αλήθειας. Οι in-memory cache υπάρχουν για να περιορίζουν επαναλήψεις, όχι για να αλλάζουν semantics persistence.
