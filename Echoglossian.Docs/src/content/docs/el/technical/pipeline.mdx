## Όρια σταδίων

### Capture

Το source text μπορεί να έρθει από:

- payloads `AtkValue` πριν από refresh
- ορατούς text nodes του addon
- callback payloads όπως quest toast `SeString`

### Μετάφραση

Το `TranslationService` συντονίζει την κοινή ροή μετάφρασης. Οι concrete translators παραμένουν engine-specific και πρέπει να κατέχουν μόνο provider-specific request και response handling.

### Παρουσίαση

- Το overlay mode κάνει render το μεταφρασμένο κείμενο έξω από το native UI.
- Το native mode μπορεί να γράψει μεταφρασμένο κείμενο σε υποστηριζόμενους nodes ή payloads.
- Το swap mode κρατά μεταφρασμένο native text και χρησιμοποιεί το overlay για το original text.

### Persistence και reuse

Οι οντότητες διαλόγου και toast χρησιμοποιούν persisted history μαζί με in-memory suppression για να αποφεύγουν επαναλήψεις. Μια late completion δεν πρέπει να αντικαθιστά νεότερο visible state όταν το capture scope της έχει πια παλιώσει.
