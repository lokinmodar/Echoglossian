## Εγκαταστήστε το plugin

Εγκαταστήστε το Echoglossian μέσω του οικοσυστήματος launcher του FFXIV και της πηγής plugin που ήδη χρησιμοποιείτε για Dalamud plugins.

## Λίστα ελέγχου πρώτης εκτέλεσης

1. Ανοίξτε το παράθυρο ρυθμίσεων του Echoglossian με `/eglo`.
2. Επιλέξτε τη γλώσσα προέλευσης και τη γλώσσα στόχου με τις οποίες θέλετε να δουλέψετε.
3. Επιλέξτε μια μηχανή μετάφρασης που υποστηρίζει τη γλώσσα στόχου σας.
4. Εισαγάγετε τα δικά σας διαπιστευτήρια provider στο UI του plugin αν η μηχανή το απαιτεί.
5. Ενεργοποιήστε τις επιφάνειες που θέλετε να μεταφράζονται.

## Κανόνες ενεργοποίησης

Η καθολική μετάφραση δεν παραμένει ενεργή εκτός αν ισχύουν όλα τα ακόλουθα:

- Η επιλεγμένη μηχανή είναι έγκυρη για την επιλεγμένη γλώσσα στόχου.
- Η ρύθμιση του provider είναι πλήρης.
- Υπάρχουν όλα τα απαιτούμενα κατεβασμένα font assets για τη γλώσσα στόχου.

## Διαπιστευτήρια και κλειδιά

Τα διαπιστευτήρια provider εισάγονται από τον παίκτη μέσα από το UI ρυθμίσεων του plugin. Αυτός ο ιστότοπος τεκμηρίωσης δεν δημοσιεύει ούτε απαιτεί secrets του repository.

Χρησιμοποιείτε μόνο placeholders όπως `sk-example` στα παραδείγματα. Μην αντιγράφετε ποτέ πραγματικό API key σε screenshots ή κοινόχρηστα logs.
