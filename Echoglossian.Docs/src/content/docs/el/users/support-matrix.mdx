Αυτή η σελίδα είναι η δημόσια έκδοση του τρέχοντος αποθέματος επιφανειών μετάφρασης. Τεκμηριώνει μόνο πραγματική συμπεριφορά runtime.

## Οικογένειες λειτουργίας

| Οικογένεια λειτουργίας | Λειτουργίες | Χρησιμοποιείται από |
| --- | --- | --- |
| Οικογένεια quest / native-window | `Native UI Translation`, `Tooltip Translation Only`, `Native UI Translation With Original Tooltips` | Επιφάνειες οικογένειας Journal και DB-first game windows |
| Οικογένεια overlay | `Native UI Translation`, `Overlay Translation Only`, `Native UI Translation With Original Overlay` | Talk, BattleTalk, υπότιτλοι, MiniTalk, CutSceneSelectString και επιφάνειες οικογένειας toast |

## Λειτουργικές σημειώσεις

- Ορισμένες γλώσσες απαιτούν κατεβασμένα font assets πριν η μετάφραση μπορέσει να ενεργοποιηθεί με ασφάλεια.
- Οι overlay-only γλώσσες εξομαλύνονται μακριά από native replacement λειτουργίες όταν η native εμφάνιση θα ήταν μη ασφαλής.
- Μια επιφάνεια μπορεί να υπάρχει στη ρύθμιση ή στον κώδικα αλλά να παραμένει σκόπιμα κρυφή ή απενεργοποιημένη σε release.
