## Βασικές ρυθμίσεις

Η ελάχιστη χρήσιμη ρύθμιση είναι:

- μία γλώσσα προέλευσης
- μία γλώσσα στόχου
- μία μηχανή μετάφρασης που υποστηρίζει αυτό το ζεύγος
- μία έγκυρη ρύθμιση provider όταν η μηχανή απαιτεί διαπιστευτήρια ή endpoint

## Ρύθμιση μηχανής

Διαφορετικές μηχανές εμφανίζουν διαφορετικά πεδία, αλλά οι δημόσιες κατηγορίες είναι σταθερές:

- πεδία διαπιστευτηρίων provider όπως API key
- επιλογή μοντέλου για μηχανές βασισμένες σε LLM
- προαιρετικό custom endpoint ή URL τοπικού runtime
- επιλογές σχετικές με prompt για μηχανές που είναι prompt-aware

Αν μια μηχανή δεν είναι διαθέσιμη για την επιλεγμένη γλώσσα στόχου, αλλάξτε είτε τη μηχανή είτε τη γλώσσα στόχου πριν προσπαθήσετε να ενεργοποιήσετε τη global μετάφραση.

## Toggles επιφανειών

Αφού ο global translator είναι υγιής, ενεργοποιήστε μόνο τις επιφάνειες που θέλετε:

- επιφάνειες διαλόγου και overlay
- επιφάνειες quest και journal
- επιφάνειες toast
- επιφάνειες game-window

Κάθε οικογένεια διατηρεί τα δικά της toggles σε επίπεδο επιφάνειας ακόμη και μετά την ενεργοποίηση της global μετάφρασης.

## Ασφαλείς συνήθειες ρύθμισης

- Αλλάζετε μία ομάδα ρυθμίσεων κάθε φορά.
- Επιβεβαιώνετε τη συνδεσιμότητα του provider πριν ενεργοποιήσετε πολλές επιφάνειες.
- Προτιμάτε πρώτα την παρουσίαση overlay όταν δοκιμάζετε νέα γλώσσα ή νέο provider.
- Κρατάτε screenshots και εξαγόμενες ρυθμίσεις χωρίς πραγματικά provider secrets.
