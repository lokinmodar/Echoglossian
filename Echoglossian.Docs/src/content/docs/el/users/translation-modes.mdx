---
title: Τρόποι μετάφρασης
description: Κατανοήστε την παρουσίαση overlay, native και swap πριν ενεργοποιήσετε επιφάνειες.
---

Το Echoglossian αντιμετωπίζει το capture, τη μετάφραση, το overlay rendering και το native mutation ως ξεχωριστά στάδια. Ο τρόπος παρουσίασης αποφασίζει ποια στάδια επιτρέπεται να αγγίζουν το ζωντανό game UI.

## Μόνο μετάφραση overlay (`Overlay Translation Only`)

Χρησιμοποιήστε τη λειτουργία overlay όταν θέλετε μεταφρασμένο κείμενο χωρίς να μεταβάλλετε το native addon.

- Το πηγαίο κείμενο συλλαμβάνεται.
- Η μετάφραση εκτελείται κανονικά.
- Το μεταφρασμένο αποτέλεσμα αποδίδεται μόνο στο overlay.
- Το native addon παραμένει μόνο για ανάγνωση.

Αυτή είναι η ασφαλέστερη λειτουργία για πυκνές ή ασταθείς επιφάνειες.

## Μετάφραση native UI (`Native UI Translation`)

Χρησιμοποιήστε τη native λειτουργία όταν θέλετε το μεταφρασμένο κείμενο να γραφτεί σε υποστηριζόμενες native επιφάνειες.

- Το capture και η μετάφραση εξακολουθούν να γίνονται πρώτα.
- Το μεταφρασμένο αποτέλεσμα μπορεί να γραφτεί στο ζωντανό addon.
- Η ποιότητα του layout εξαρτάται από το πόσο καλά η συγκεκριμένη επιφάνεια υποστηρίζει native replacement.

## Μετάφραση native UI με αρχικό overlay (`Native UI Translation With Original Overlay`)

Η λειτουργία swap κρατά το μεταφρασμένο κείμενο στο native UI και χρησιμοποιεί το overlay για να εμφανίσει το αρχικό κείμενο.

Αυτό είναι χρήσιμο όταν θέλετε το UI μεταφρασμένο αλλά χρειάζεστε ακόμη το αρχικό κείμενο κοντά ως αναφορά.

## Πώς να επιλέξετε

Ξεκινήστε με τη λειτουργία overlay αν:

- δοκιμάζετε νέα μηχανή
- δοκιμάζετε νέα γλώσσα
- εργάζεστε με πυκνή επιφάνεια όπως journals ή μεγάλους διαλόγους

Μετακινηθείτε σε native ή swap μόνο αφού η επιφάνεια στόχου συμπεριφέρεται αρκετά καλά για τη ρύθμισή σας.
