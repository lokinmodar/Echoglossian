Το Echoglossian είναι ένα plugin για Dalamud που μεταφράζει υποστηριζόμενες επιφάνειες κειμένου του Final Fantasy XIV σε πραγματικό χρόνο.

Αυτή η δημόσια τεκμηρίωση χωρίζεται σε δύο κοινά:

- Χρήστες του plugin που χρειάζονται οδηγίες για εγκατάσταση, ρύθμιση, επιλογή τρόπου λειτουργίας και αντιμετώπιση προβλημάτων.
- Συνεισφέροντες που χρειάζονται αναφορά για την αρχιτεκτονική, το runtime και την ανάπτυξη.

## Τι καλύπτει αυτός ο ιστότοπος

- Εγκατάσταση του plugin από το οικοσύστημα launcher που ήδη χρησιμοποιείτε.
- Ρύθμιση γλώσσας προέλευσης και γλώσσας στόχου.
- Επιλογή provider μετάφρασης και εισαγωγή των δικών σας διαπιστευτηρίων στο UI του plugin.
- Κατανόηση του πότε είναι κατάλληλη η παρουσίαση overlay, native και swap.
- Έλεγχος για το ποιες επιφάνειες είναι αυτή τη στιγμή τεκμηριωμένες ως υποστηριζόμενες.

## Τι δεν δημοσιεύει αυτός ο ιστότοπος

- Secrets του repository ή ενεργά διαπιστευτήρια.
- Εσωτερικές σημειώσεις handoff, backlogs ή ιδιωτικά πρόχειρα workflow.
- Οδηγίες release-maintainer για εξωτερικά manifests.
