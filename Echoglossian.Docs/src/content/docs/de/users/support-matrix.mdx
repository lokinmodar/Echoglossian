Diese Seite ist die öffentliche Version des aktuellen Inventars der Übersetzungsflächen. Sie dokumentiert ausschließlich reales Runtime-Verhalten.

## Modusfamilien

| Modusfamilie | Modi | Verwendet von |
| --- | --- | --- |
| Quest-/native-window-Familie | `Native UI Translation`, `Tooltip Translation Only`, `Native UI Translation With Original Tooltips` | Journal-Familienflächen und DB-first game windows |
| Overlay-Familie | `Native UI Translation`, `Overlay Translation Only`, `Native UI Translation With Original Overlay` | Talk, BattleTalk, Untertitel, MiniTalk, CutSceneSelectString und Toast-Familienflächen |

## Betriebshinweise

- Einige Sprachen benötigen heruntergeladene Font-Assets, bevor die Übersetzung sicher aktiviert werden kann.
- Overlay-only-Sprachen werden von native replacement-Modi weg normalisiert, wenn native Darstellung unsicher wäre.
- Eine Fläche kann in Konfiguration oder Code existieren und in einem Release trotzdem bewusst verborgen oder deaktiviert sein.
