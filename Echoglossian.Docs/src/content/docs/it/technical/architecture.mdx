## Aree principali di runtime

- `NativeUI/AddonHandlers/...` per il comportamento di acquisizione e presentazione specifico dell’addon
- `NativeUI/Handlers/...` per helper native condivisi e coordinamento del runtime
- `UIOverlays/TranslationOverlay/...` per stato e rendering dell’overlay
- `Translators/TranslationService` per il flusso di traduzione condiviso
- `LanguagesHandling/...` per metadati di lingua e disponibilità degli engine
- `DBHelpers/...` ed entità di messaggi supportate da EF per lo storico persistito delle traduzioni

## Regole architetturali

- Il nuovo lavoro deve riutilizzare la pipeline di traduzione condivisa invece di creare una coda parallela.
- La modalità overlay-only deve lasciare la native game UI in sola lettura.
- Le modalità native e swap possono mutare la native UI solo sulle superfici che lo supportano esplicitamente.
- Il database resta la fonte di verità. Le cache in memoria servono a sopprimere lavoro ripetuto, non a ridefinire la semantica di persistenza.
