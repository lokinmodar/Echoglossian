## Installa il plugin

Installa Echoglossian tramite l’ecosistema di launcher FFXIV e la sorgente di plugin che già usi per i plugin Dalamud.

## Checklist del primo avvio

1. Apri la finestra di configurazione di Echoglossian con `/eglo`.
2. Scegli le lingue di origine e di destinazione con cui vuoi lavorare.
3. Seleziona un motore di traduzione che supporti la tua lingua di destinazione.
4. Inserisci la tua credenziale del provider nell’UI del plugin se il motore la richiede.
5. Abilita le superfici che vuoi tradurre.

## Regole di attivazione

La traduzione globale non rimane abilitata a meno che tutte le condizioni seguenti siano vere:

- Il motore selezionato è valido per la lingua di destinazione selezionata.
- La configurazione del provider è completa.
- Sono presenti eventuali asset di font scaricati richiesti per la lingua di destinazione.
