Questa pagina è la versione pubblica dell’attuale inventario delle superfici di traduzione. Documenta solo il comportamento reale di runtime.

## Famiglie di modalità

| Famiglia di modalità | Modalità | Usata da |
| --- | --- | --- |
| Famiglia quest / native-window | `Native UI Translation`, `Tooltip Translation Only`, `Native UI Translation With Original Tooltips` | Superfici della famiglia Journal e game window DB-first |
| Famiglia overlay | `Native UI Translation`, `Overlay Translation Only`, `Native UI Translation With Original Overlay` | Talk, BattleTalk, subtitles, MiniTalk, CutSceneSelectString e superfici della famiglia toast |

## Note operative

- Alcune lingue richiedono asset di font scaricati prima che la traduzione possa attivarsi in sicurezza.
- Le lingue overlay-only vengono normalizzate fuori dalle modalità di sostituzione native quando la visualizzazione native sarebbe insicura.
- Una superficie può esistere nella configurazione o nel codice ma essere comunque intenzionalmente nascosta o disabilitata in una release.
