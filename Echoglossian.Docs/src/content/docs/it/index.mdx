## Ambito pubblico

Questo sito pubblica solo documentazione curata.

- L’uso, la configurazione e la risoluzione dei problemi del plugin sono pubblicati qui.
- L’architettura attuale, il flusso di runtime e la guida per i contributori sono pubblicati qui.
- Handoff interni, note di release, piani e materiale di backlog restano nell’albero `docs/` del repository e non vengono pubblicati da questo sito.

## Modello di localizzazione

Il sito espone lo stesso elenco di locale dei file di risorse del plugin. L’inglese è la locale sorgente neutra. Se una pagina localizzata non esiste ancora, Starlight mostra la pagina inglese con il suo avviso integrato di contenuto non tradotto invece di produrre una route rotta.
